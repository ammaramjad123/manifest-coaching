How to Edit Your Website

The Peace Practice — Simple Guide
Good news — you can update your website yourself, free, from any computer.
Your website is hosted free on Vercel, and its files live on a website called GitHub. You make all your changes on GitHub (just typing in your web browser). When you save, your live website updates automatically in about 2 minutes — no apps, no coding.

Part 1 · How to Edit & Publish (do this every time)

  1. Go to github.com and sign in, then open your project (your developer will send you the link).
  2. Open the folder src, then the folder config.
  3. Click the file you want to change (see Part 2 and Part 3 below).
  4. Click the pencil ✏️ button (top-right of the file) to start editing.
  5. Make your change — only the words inside the "quotes".
  6. Click the green "Commit changes" button, then "Commit changes" again in the pop-up.
  7. Wait about 2 minutes, then refresh your website — your change is live. Done!

Part 2 · Change a Picture

File: src/config/siteImages.js

  1. First, upload your new image to the public/new folder.
    (On GitHub: open public → new → "Add file" → "Upload files" → drag your image in → Commit changes.)
  2. Open src/config/siteImages.js and edit it (Part 1 steps 4–7).
  3. Find the picture you want to change — each line has a note saying where it appears.
  4. Change the name inside the quotes to your new image, e.g. "/new/my-new-photo.jpg"
  5. Commit changes. Your picture updates in a couple of minutes.
Picture tips: Always start with /new/ · Type the file name exactly, including .jpg or .png · Keep the quotes " ".

Part 3 · Edit the "Upcoming Training" Section

File: src/config/upcomingTraining.js — everything is in here.

A  Show or hide the whole section

  1. At the top, find active: true
  2. active: true → the section shows  ·  active: false → hidden (use when no training is coming up).

B  Change the training details

  1. when: — type the dates, e.g. "March 14–16, 2026"
  2. where: — type the location, e.g. "Atlanta, GA · In person"
  3. Also change title, cost, etc. inside their quotes.
  4. Bullet points (whatToExpect): each line is one bullet — copy a line to add one, delete a line to remove one.

C  You have two trainings (ART & SĀF-T)

  • Each training has its own active: true — set one to false to hide just that one.
  • To add a new training, copy a whole block { ... } and change the words.
3 Golden Rules (never break these)
  • Only change the words inside the "quotes".
  • Never delete the quotes " " or the commas ,.
  • File names must match the real file exactly (letters, dashes, .jpg/.png).

Your web address: your custom domain is connected to the site one time by your developer — after that, you never have to touch it. Every edit you make on GitHub goes live on your domain automatically.
